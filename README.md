# Линия — второй проект портфолио

Демонстрационный сайт вымышленного салона красоты. Создан 28 сентября 2026 года.

## Что работает

- Адаптивная страница с услугами, описанием подхода, ответами на вопросы и выбором времени.
- Пробная запись: выбор услуги, одного из четырёх ближайших дней и времени; просмотр итогов в диалоге.
- Выбор можно сохранить в `sessionStorage` текущей вкладки. Личные данные не запрашиваются.
- Клавиатурная навигация и поддержка настройки сокращённого движения.
- Два WebMCP-инструмента в браузерах с поддержкой этого API: выбор пробной записи и чтение текущего выбора.

## Ограничения

Это учебный проект, не действующий салон. Услуги, длительность и свободные слоты условные. Настоящая бронь не создаётся, данные не передаются владельцу и не синхронизируются между устройствами. CRM, уведомления, проверка занятости и оплата не подключены. Изображение создано ImageGen для концепции и не показывает реального клиента.

## Запуск

Из этой папки: `node serve.mjs`. Открыть `http://127.0.0.1:4174`. Установка зависимостей не нужна. Для размещения используются файлы из `dist`.

## Карточка для портфолио

**Линия / Сайт салона красоты.** Учебный проект. Задача — представить услуги и дать посетителю выбрать удобное время. Реализованы адаптивная страница, выбор услуги, дня и времени, просмотр и локальное сохранение пробной записи. Реальная бронь и уведомления не входят в демонстрацию.
